# 公开聚合证据说明

四个CSV来自固定R27结果的脱敏聚合表，内容字节与源对象一致，共3136字节。哈希和计算复核见上级checks.json。

这些表含同三个正常局部码头过程，在三种条件配置下的合计值。每种配置是一种独立计算口径。episodes列的3表示过程数；独立船舶数及同船重复关系未在这些聚合表中披露。

ME为主机，AE为辅机，AB为锅炉。CO2_kg单位为kg，duration_h和hours为小时。基础BSFC燃料与CO₂低负荷修正分别列出；调整后的CO₂属于清单算法输出。STATE_AMBIGUOUS为已观测但运行状态不充分明确的时段；TIME_UNKNOWN为缺少时间观测支持的时段。

门线变体由同一正常资料设计，属于内部几何敏感性。当前经验事件差、当地风浪附加量与外部实测精度均未取得。表中正常排放、零缺测和零状态时长不能用来推定气旋净效应。

数据保留足够精度供算术追溯，科学描述通常使用合理位数。没有船舶ID、坐标、个体调用时间、商业参数或原始轨迹。
