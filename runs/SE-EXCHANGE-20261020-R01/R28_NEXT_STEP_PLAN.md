# R28下一步建议：共同支持先行，真实比较按条件进入

日期2026-10-20。状态PROPOSED_PENDING_FINAL_EXECUTION_SCOPE。

本次公开归档与外部评阅不启动新的经验任务。以下继承R13后的R28规划，并提出明确的科学停止条件。

## 1. 本轮必须回答的问题

在现有资料与限定候选内，能否建立一组具有真实气旋阶段依据、同实际设施、同技术子类型和可比任务的事件—正常过程？建立后，碳差相对于正常波动和主要模型误差是否能够解释？

前三个正常清单已完成技术验证。追加类似正常清单的边际信息有限。本轮主要价值取决于共同支持和真实事件关联。

## 2. 联合审查与冻结顺序

先在有限候选表中同时登记terminal、subtype、external_phase、normal_support、observation_quality、parameter_support。实际地点T01优先复用；一个其他地点作为事前声明的替代。最多2设施、2风暴、16正常候选和4事件候选，最终锁1个事件与至少4个正常过程。

外部事件阶段来自可核实的预报、实际天气、关闭／恢复公告。宽时间邻近窗是检索范围；较晚恢复阶段需独立支持。船舶明显减速、等待或碳差大小不参与处理资格。

先完成有限的共同支持盘点，再按事前规则固定最终样本和正常资料几何。原锁定失败记录继续保留。样本顺序、替代原因、源版本和曾经查看过的历史信息写入新锁。

完成调用构成一个条件总体。气旋导致的撤离、改港、取消信息未知和未完成调用另列名册。没有可观测完成过程的对象，不填零排放，也不将其静默移出风险总体。若原问题需要它们，应重新决定更强的数据需求。

## 3. 实际比较接口

在新版本中接通通过资格后的normal_loo与paired_contrast调用，使用正／负／零差和拒绝样例验证调度。日期从目标起终点生成，跨年与缓存范围逐项登记。TIME_UNKNOWN的界限进入事件与全部正常供体的差值，STATE_AMBIGUOUS另列参数范围。

核对EPA碳因子和尺寸表来源定位。共同目标参数作用于事件与供体，所有状态和机组采用同一供体权重。单个正常自身参数清单与共同参数反事实分别命名。

## 4. 优先检验真正主导的参数

当前97.12%时间靠泊，新增范围应有依据地覆盖装载／卸载或服务任务、AE/AB运行负荷、锅炉、燃料与岸电。没有分布依据时采用条件情景；情景比例不写成客观符号概率。

同时报告原始时长、状态、距离、速度和CO₂。解释中说明有多少碳变化源自可观察活动差，有多少取决于默认负荷。当前三配置覆盖模糊状态的范围不能代表总精度。

## 5. 验收与科学停止条件

| 情况 | 后续处理 |
|---|---|
| 外部事件、设施、子型、正常及观测均合格 | 执行一组条件碳比较、正常留出及逐供体范围 |
| 技术计算成立，净差与正常误差同量级或关键配置改变方向 | 保留条件数值，结论为INCONCLUSIVE |
| 有限候选内无共同支持 | 报告失败条件和最小额外资料，结束该候选搜索 |
| 有效样本持续集中于静止靠泊 | 将成果定位为停靠模块，重新评估原航行五通道目标 |
| 净差稳定且有超出时长换算的新机制证据 | 再计划更多独立风暴、完整活动范围和外部精度检验 |

四个正常过程是技术留出设计目标，不能单独保证功效、独立性或因果识别。成功可以得到正差、负差、小差异或证据不足。安全建议与研究碳界限各有证据要求。

## 6. 有界预算提案

一轮3小时含25分钟封存；4CPU、8GiB内存、16GiB来源读取、2GiB新私有输出、100MiB官方支持资料、10MiB脱敏发布、10万观测配置评价。沿现有授权环境；HPC迁移、扩年、采购、外部联系和稿件改动另行决定。这些数值是拟议上限，正式执行合同需明确采用。

先保留约45分钟用于共同支持和外部时钟审查。若关键支持不成立，封存证据即可；剩余预算不会自动转为更多合成演示或不断扩大候选。合成测试按新接口的必要需求安排。

## 7. 请求外部评阅者挑战的决定

请重点判断：同码头完成过程能否对原净效应问题提供足够信息；是否更适合转向稳定覆盖的航行门间通过；补充完整离岸轨迹或实际负荷资料的必要性；何时应停止局部靠泊路线。每种替代应说明可获得资料与观察范围，而不预设其一定优于当前方案。
