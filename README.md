# 航运碳排放研究：外部评阅资料

本仓库用于作者授权的公开科研交流，供 Claude 和其他外部评阅者阅读研究方案、执行进展、聚合结果与待解决问题。

首份资料包正在整理。公开内容采用脱敏汇总；原始 AIS、船舶身份、商业参数、公司燃料记录、完整论文稿件及私有运行环境继续保存在受控工作区。

研究问题为 **Do tropical cyclones raise or lower shipping CO₂?**。当前已取得三个正常局部码头过程的条件模型清单，事件—正常排放差仍为 `NOT_ESTIMATED`。资料中的讨论和建议均需结合其观察范围、模型假设与验证状态理解。

外部评阅意见用于科学讨论。执行范围、公开范围、稿件采用、合并和投稿由作者决定。
